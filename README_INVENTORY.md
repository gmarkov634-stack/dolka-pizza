# Обновление сайта «Долька»

В админку добавлена вкладка **«Склад и прибыль»**.

В ней доступны:

- остатки ингредиентов;
- приход, списание и инвентаризация;
- настройка цены упаковки, минимального и целевого остатка;
- список закупки;
- история движений;
- прямая себестоимость каждого товара;
- ожидаемый маржинальный доход с одной продажи.

В разделе «Настройки» добавлен переключатель **«Автоматический складской учёт»**. Он должен оставаться выключенным, пока не внесены фактические остатки.

Для публикации загрузите все файлы этого каталога в корень репозитория `dolka-pizza`. GitHub Pages обновится после завершения публикации ветки.
